# Reporting a vulnerability

Report security issues privately through [GitHub's vulnerability reporting form](https://github.com/KristijanPruzinac/ekipa/security/advisories/new). Include reproduction steps and the affected page or API route. Do not post credentials, private submissions or exploit details in public issues.

The production service is https://wagz.com.hr. Only the current deployed release is supported. See [the security review](docs/SECURITY-REVIEW.md) for controls and remaining limitations.
