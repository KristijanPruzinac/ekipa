# WagZ release review queue

Requested and reviewed **3 October 2026**. Status reflects the bounded [application security](SECURITY-REVIEW.md), [SEO and accessibility](SEO-REVIEW.md), [operations/platform](OPERATIONS-REVIEW.md) and [event coverage](COVERAGE-AUDIT.md) reports. The original reports retain their baseline/local-test wording; the reviewed application fixes and workflow pins are now committed, and the application fixes are included in production. **Reviewed; open** means evidence was gathered and residual work remains. **Not verified** identifies an untested boundary. Release `f696ae2` passed the original production matrix; later release `219c4e9` includes the custom-domain/IndexNow changes. The latest **10:31 Zagreb** GET-only matrix passed for apex and legacy hosts using Google resolution with normal TLS: homepage/detail 200, 23 events, 24 canonical sitemap URLs, editor noindex, anonymous admin 401 and path/query-preserving `www` 308. Evidence: `.artifacts/release-live-report.json`, `.artifacts/domain-launch-report.json` and the [deployment note](DEPLOYMENT.md). Production-verified statuses apply only to observed responses; ordinary DNS still fails on some resolvers. These reports are not security certification or a claim that the queue is complete.

Scope: React/Vite web client, Flutter client, Express API, Vercel, Neon Postgres, GitHub Actions, Jina source collection and bounded OpenRouter processing. The pilot has a shared administrator key and public event submissions; there are no public user accounts. The historical Supabase project is outside this runtime. This document itself changes no deployment gate or production configuration.

Use [OWASP ASVS 5.0.0](https://owasp.org/projects/asvs) and the [OWASP Web Security Testing Guide](https://owasp.org/projects/web-security-testing-guide) for requirements and methods. The author's [vibe-coding checklist](https://asanchez.dev/blog/the-security-checklist-for-vibe-coders/) and [community checklist repository](https://github.com/astoj/vibe-security) remain supplementary reading, not verification evidence. Reports record reproducible findings and limits; existing functional tests alone do not complete this queue.
