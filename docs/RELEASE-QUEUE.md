# WagZ release review queue

Requested and reviewed **3 October 2026**. Status now reflects the bounded [application security](SECURITY-REVIEW.md), [SEO and accessibility](SEO-REVIEW.md), [operations/platform](OPERATIONS-REVIEW.md) and [event coverage](COVERAGE-AUDIT.md) reports. **Fixed locally** means working-tree changes with recorded checks, not a deployment or production verification. **Reviewed; open** means evidence was gathered and residual work remains. **Not verified** identifies an untested boundary. Production release `f696ae2` was subsequently verified by the deployment owner with a GET-only matrix on 3 October 2026 at 07:24 UTC; evidence is `.artifacts/release-live-report.json` and the [deployment note](DEPLOYMENT.md). Production-verified statuses below apply only to those observed responses. The original review baselines remain intact. These reports are not security certification or a claim that the queue is complete.

Scope: React/Vite web client, Flutter client, Express API, Vercel, Neon Postgres, GitHub Actions, Jina source collection and bounded OpenRouter processing. The pilot has a shared administrator key and public event submissions; there are no public user accounts. The historical Supabase project is outside this runtime. This document itself changes no deployment gate or production configuration.

Use [OWASP ASVS 5.0.0](https://owasp.org/projects/asvs) and the [OWASP Web Security Testing Guide](https://owasp.org/projects/web-security-testing-guide) for requirements and methods. The author's [vibe-coding checklist](https://asanchez.dev/blog/the-security-checklist-for-vibe-coders/) and [community checklist repository](https://github.com/astoj/vibe-security) remain supplementary reading, not verification evidence. Reports record reproducible findings and limits; existing functional tests alone do not complete this queue.
