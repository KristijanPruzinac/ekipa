# WagZ release review queue

Requested and recorded **3 October 2026**. All items below are **queued**, not completed audits or confirmed vulnerabilities. This document creates no deployment gate or production configuration change by itself.

Scope: React/Vite web client, Flutter client, Express API, Vercel, Neon Postgres, GitHub Actions, Jina source collection and bounded OpenRouter processing. The pilot has a shared administrator key and public event submissions; there are no public user accounts. The historical Supabase project is outside this runtime.

Use [OWASP ASVS 5.0.0](https://owasp.org/projects/asvs) for requirements and the [OWASP Web Security Testing Guide](https://owasp.org/projects/web-security-testing-guide) for verification methods. The author's [vibe-coding checklist](https://asanchez.dev/blog/the-security-checklist-for-vibe-coders/) and [community checklist repository](https://github.com/astoj/vibe-security) are supplementary reading, not proof of a completed review. Record each finding with affected code, reproducible evidence, severity and a fix or accepted limitation.
