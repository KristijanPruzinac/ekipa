The following record describes earlier releases and the gaps observed at those times. Use the current candidate table above for today’s status; retain the old evidence as provenance, not as a current assertion that safeguards are disabled.

The original reports retain their baseline/local-test wording; the reviewed application fixes and workflow pins are now committed, and the application fixes are included in production. **Reviewed; open** means evidence was gathered and residual work remains. **Not verified** identifies an untested boundary. Release `f696ae2` passed the original production matrix; later release `219c4e9` includes the custom-domain/IndexNow changes. The latest **10:31 Zagreb** GET-only matrix passed for apex and legacy hosts using Google resolution with normal TLS: homepage/detail 200, 23 events, 24 canonical sitemap URLs, editor noindex, anonymous admin 401 and path/query-preserving `www` 308. Production-verified statuses apply only to observed responses; ordinary DNS still fails on some resolvers. These reports are not security certification or a claim that the queue is complete.

This document itself changes no deployment gate or production configuration.

Use [OWASP ASVS 5.0.0](https://owasp.org/projects/asvs) and the [OWASP Web Security Testing Guide](https://owasp.org/projects/web-security-testing-guide) for requirements and methods.
