### Croatian homepage wording follow-up

The local homepage title and Open Graph title are now **Događaji u Osijeku | WagZ**. Its description and Open Graph description read: “Pronađi koncerte, predstave, radionice i druga događanja u Osijeku. Datumi, lokacije i izvorne najave na jednom mjestu.” The visible feed heading is **Događanja u Osijeku**, and the hero introduction starts “Koncerti, predstave, radionice i izlasci.” Event pages keep their individual source-backed titles, descriptions and facts.

This uses descriptive Croatian wording rather than repeated query variants. Google recommends concise, descriptive titles and can match related search terms without every exact variation appearing on the page. Google may choose a different result title or snippet; wording changes do not establish rankings or indexing. [Title guidance](https://developers.google.com/search/docs/appearance/title-link), [search-term guidance](https://developers.google.com/search/docs/fundamentals/seo-starter-guide#expect-your-readers-search-terms), [snippet guidance](https://developers.google.com/search/docs/appearance/snippet).

The focused nine HTTP tests and `test:seo` passed after this copy change. Tests verify the initial HTML title/description/OG tags, visible h2, Croatian language markup, crawlable links, robots/sitemap and retained event schema. Browser checks passed at 1440/390/320 px, including hydration, permalink navigation and absence of audience labels. The heading wraps cleanly at 320 px without document overflow. Evidence: `.artifacts/seo-pages-1791013136917/`, including `homepage-320.png`, `homepage-1440.png`, `events-heading-320.png`, `events-heading-1440.png` and `report.json`. This follow-up does not change ongoing-event controls, sources, routing or the live canonical origin.

The origin is explicit in `shared/site.ts`, never derived from the Host header. Canonical/share/sitemap references now use `https://wagz.com.hr`; old-host redirects are deliberately deferred until resolver propagation is ready, retaining the old homepage and mobile API. Sitemap `lastmod` uses records rather than fabricated build dates. [Google sitemap guidance](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap), [canonical guidance](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls).

Valid schema and source-backed facts do not establish rich-result eligibility for restricted school/membership events. Croatia/Croatian are absent from Google's published event-experience availability table. Rich results or rankings must not be promised. [Google Event guidance](https://developers.google.com/search/docs/appearance/structured-data/event).

## Accessibility and interaction

- **Keyboard/history:** Enter opens the named native dialog. Close/Escape return focus to its opener after browser hash-history restoration. Back/Forward restores meaningful event URLs. Closed tip-dialog history entries are reused to avoid phantom Back stops. Source links open separate tabs. Admin and tip flows remain covered by the review suite.
- **Content/structure:** Visible labels, source names and definition-list facts remain; decorative SVGs are hidden from accessibility APIs. Direct pages highlight original sources and current listings. Historical pages clearly explain past dates.
- **Narrow layouts:** No document overflow in sampled 320/390/1440 cards, filters, timeline and direct pages. Header, source/reset/close actions remain reachable. Mobile timeline starts collapsed. End markers stay compact and noninteractive.
- **Activity selection:** A named button group exposes one `aria-pressed` selection: Sve plus present primary categories/counts. It filters ongoing/cards/timeline together without sorting. Dance workshops count as dance. Disappearing selected types produce an empty state/reset. No audience filter or saved preference.
- **Contrast/non-color cues:** Labels and distinct motifs accompany category colors. New rose/blue text-background pairs exceed 4.5:1 in Flutter calculation tests. Earlier sampled web text pairs were 5.77:1–16.65:1. All hover/disabled/error/border states were not exhaustively measured. [WCAG guidance](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html).
- **Limits:** Enlarged web pills/legend and Flutter legend were checked at 320 px; this does not replace full 200% text-only zoom, screen-reader, switch-control, real-device or complete Flutter accessibility testing.
